# Telegram AI Multi-Bot 🤖

Універсальний Телеграм-бот, інтегрований з ChatGPT (OpenAI API). Бот підтримує інтерактивні текстові діалоги, 
проведення тематичних квізів із підрахунком балів, інтелектуальний переклад на різні мови, а також систему рекомендацій 
медіаконтенту з можливістю фільтрації нецікавих варіантів.

## 🚀 Функціонал

Бот підтримує наступні команди головного меню:
* **Головне меню (`/start`)** — Вітання користувача та ініціалізація головного меню.
* **Цікаві факти (`/random`)** — Генерація випадкових та захоплюючих фактів за допомогою ШІ.
* **Задати питання чату GPT (`/gpt`)** — Режим прямого спілкування з ChatGPT асистентом.
* **Поговорити з відомою особистістю (`/talk`)** — Рольовий діалог з обраним персонажем (Курт Кобейн, Королева Єлизавета II, Дж. Р. Р. Толкін,
  Фрідріх Ніцше, Стівен Гокінг).
* **Взяти участь у квізі (`/quiz`)** — Інтерактивна вікторина на теми програмування (Python), математики чи біології із веденням
  динамічного рахунку правильних відповідей.
* **Перекладач (`/translate`)** — Швидкий переклад надісланого тексту на одну з обраних мов (англійська, іспанська, німецька, польська, українська).
* **Рекомендації (`/recommend`)** — Персональний підбір фільмів, книг чи музики за жанром. Має кнопку «Не подобається», яка
  виключає поточний твір та адаптує наступні рекомендації ШІ без повторів.
